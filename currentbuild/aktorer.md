## Aktorer

### Aktører og roller

| | |
| :--- | :--- |
| Pasient | Måler blodtrykket hjemme med en tilkoblet måler og app, og sender inn målingene. |
| Sykepleier eller lege | Går gjennom innsendte målinger, vurderer dem og avgjør eventuell oppfølging. |
| Journalsystem | Mottar målingene, viser dem for helsepersonell og lagrer vurderte målinger i journalen. |
