# Informasjonsbehov

| Aktør | Steg | Informasjon og behov |
|---|---|---|
| Pasient | 1 | Egen identitet, blodtrykksapparat og tidspunkt for målingen. |
| Måleapp | 2 | Pasient, tidspunkt, apparat, systolisk og diastolisk verdi; bekreftelse på innsending. |
| Sykepleier eller lege | 3 | Pasient, innkomne verdier, tidspunkt og apparat; tydelig status som ikke vurdert. |
| Sykepleier eller lege | 4 | Målingen som skal vurderes, og mulighet til å registrere vurderer og vurderingstidspunkt. |
| Journalsystem | 2–4 | Motta og knytte målingen til riktig pasient; vise status og lagre vurdert måling med sporbarhet. |
